# Changelog

## 2026.11.23-native-inputs-1

- Move 15 conditional ColorBlindness variants and six unsupported Warp originals to Complete / Preview only. Materials Only now contains 826 materials; Complete retains 1,119, including 293 Preview only.
- Correct native UV and vertex-colour declarations while retaining UV inputs for mixed shaders.
- Add source-textured vertex-alpha transition layers to 14 materials, with an editable English example.
- Include source-resource catalogue cleanup and omit empty categories per edition. Existing effect badges remain; no customization letter badges are included.

## 1.0.0 asset refresh — 2026-11-17

- Added adjustable animated previews to the five ordinary water materials, following the two-layer UV motion recovered from compiled game shaders.
- Smoothed height-texture sampling with cubic interpolation and wider bump filtering, removing the visible texel facets in close-up reflections.
- Added an editable water example and English controls/provenance notes to both editions.
- Preserved native export bindings, material counts, asset icons and catalogue identities.

The existing release tags and two-ZIP layout are retained for this owner-requested refresh. Updated assets have new checksums. Previously installed libraries and already appended material copies must be replaced to receive the update.

## 1.0.0 — 2026-11-16

First standalone GitHub release, based on the V9 material library.

- **Materials Only:** 847 native-linked materials.
- **Complete Library:** 1,119 materials, including 272 Preview only assets.
- Both editions include 20 HDRI Worlds and 42 shader node-group assets.
- Relative texture paths, complete dependency packages and a Windows installer.
- English installation and usage guides, a short badge legend and an offline searchable catalogue.
- Preview assets organised under **Trackmania2020 → 08 Preview only**.
- An editable three-material example scene.

Vegetation remains preview only. ColorBlindness variants use the game's accessibility setting. Native links do not imply universal runtime compatibility.
