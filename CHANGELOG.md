# Changelog

## 1.0.0 — 2026-11-16

First standalone GitHub release, based on the V9 material library.

- **Materials Only:** 847 native-linked materials.
- **Complete Library:** 1,119 materials, including 272 Preview only assets.
- Both editions include 20 HDRI Worlds and 42 shader node-group assets.
- Relative texture paths, complete dependency packages and a Windows installer.
- English installation and usage guides, a short badge legend and an offline searchable catalogue.
- Preview assets organised under **Trackmania2020 → 08 Preview only**.
- An editable three-material example scene.

Vegetation remains preview only. ColorBlindness variants use the game's accessibility setting. Native links do not imply universal runtime compatibility.
